# Commit tags
feat: Introduces a new feature.
fix: Patches or resolves a bug.
refactor: Rewrites/restructures code without adding features or fixing bugs.
docs: Modifies documentation (e.g., README files).
test: Adds missing tests or corrects existing ones.
style: Addresses code formatting (missing semi-colons, whitespace) without altering behavior.
chore: Regular maintenance tasks, updating build dependencies, or modifying .gitignore.
